Projects

Two retrieval systems built end to end, followed by earlier work in machine learning, data and mobile.

FinRegAI

Compliance retrieval for FinTech regulation

Regulatory text is long and jurisdiction-specific. FinRegAI pulls out the exact clauses that apply to a question, filtered by jurisdiction and risk tier, from a self-curated set of 300+ regulatory PDFs.

  • Asynchronous FastAPI ingestion with LlamaIndex, using token-boundary chunking to isolate individual compliance clauses for embedding.
  • Jurisdiction and risk-tier payload filters in Qdrant avoid full index scans, keeping retrieval under 15 ms.
  • Python
  • FastAPI
  • LlamaIndex
  • Ollama
  • Qdrant

How a query flows

  1. Ingest300+ regulatory PDFs through async FastAPI
  2. ChunkToken-boundary splits, one clause per chunk
  3. EmbedVector embedding per clause
  4. Filter and retrieveQdrant payload filters by jurisdiction and risk tier
  5. AnswerLocal model served with Ollama

Cloud Academic Paper Summarizer

RAG summarization on AWS, co-led with a team of 8

A summarizer for research papers that retrieves the relevant passages first, then summarizes them, benchmarked across several LLMs to pick the best model and prompts.

  • RAG pipeline over Pinecone vector search reduced query latency by ~30%; prompt engineering and model benchmarking reached a best BERTScore of 0.89.
  • Flask backend on AWS Lambda, DynamoDB and API Gateway held 99.8% uptime and ~1.2 s responses at 10k concurrent users (5× baseline), behind a React UI.
